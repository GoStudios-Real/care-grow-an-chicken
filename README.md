# 🐔 Care & Grow An Chicken

A 3D virtual pet game by **GoStudios**. Raise, care for, and grow your own chicken!

## Play Online
🎮 **[Play in Browser](https://gostudios-real.github.io/care-grow-an-chicken/)**

## Features
- 🐣 4 evolution stages: Egg → Chick → Chicken → Adult
- 🍖 Care system: Feed, Play, Rest, Clean, Pet
- 🎮 Two mini-games: Catch & Memory Match
- 🛒 Shop with hats, accessories, toys, and themes
- 🏆 10 achievements to unlock
- 🌧️ Dynamic weather & day/night cycle
- 📱 Works on Windows, Android, and Web

## Download
- [Windows (.exe)](https://github.com/GoStudios-Real/care-grow-an-chicken/releases/latest)
- [Android (.apk)](https://github.com/GoStudios-Real/care-grow-an-chicken/releases/latest)

## Tech Stack
- Three.js (WebGL 3D rendering)
- .NET MAUI (Windows & Android wrapper)
- HTML5 / CSS3 / JavaScript
